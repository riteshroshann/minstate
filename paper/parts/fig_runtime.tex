\caption{The runtime. Every rank checks for a preemption notice at the top of each step, and one max-reduction makes
all ranks stop at the same step. Rank zero drains the configured payload and the group exits; a launcher restarts it,
at the same or a different size, from the newest complete payload. A failure that arrives without notice falls back to
the last periodic checkpoint (dashed). Because data order is a function of the step, the restarted group needs
nothing but the bundle.}
